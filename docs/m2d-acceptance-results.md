## 本次暴露并修正的问题

1. 任务路由将“不改输入或校验”误判为整轮只读。区分限定对象的禁止修改与全局只读，补充中文、英文和文件名约束的回归。
2. 运行器只向模型提供三个文件工具，但修复 Agent 提示与注册表仍包含六个工具。现在可在构造修复 Agent 时统一选择工具，运行器提供五个读取、搜索与编辑工具；未授权调用返回受审计的可恢复错误，默认产品修复工具与原通用编程工具保留。
3. 顺序共享预算使过度调查的早期案例挤占后续案例；m02 在 nc/names 已不一致后仍反复搜索，未能在轮数内落地修改。这仍是待改进项。下一轮应先分配各案例独立预算，并针对已有证据、重复调查和停止条件优化修复阶段。
