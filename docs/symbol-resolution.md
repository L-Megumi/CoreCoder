# 从已观察调用定位项目内函数定义

`resolve_project_symbol` 补充现有堆栈定位与关键词搜索：从实际读到的 Python 引用，沿本地导入、别名及包内重新导出查找定义。它读取和解析源码，不导入、执行项目，也不生成运行时调用图。

## 使用过程

1. 提取日志证据，按堆栈定位或关键词搜索找到调用处，再读取相关源码。
2. 使用返回的当前源码观察 ID、实际符号和证据 ID 调用工具；例如 `symbol="calc"` 或 `symbol="metrics.box_iou"`。
3. 工具返回实际读取的绑定/定义片段，以及引用这些观察 ID 的静态关联链。模型据此分析，并保留不确定性。

```json
{
  "symbol": "calc",
  "source_observation_id": "工具返回的实际源码观察ID",
  "evidence_ids": ["工具返回的实际证据ID"],
  "at_line": 12,
  "max_results": 6
}
```

`at_line` 可省略；同名调用出现在不同作用域时，应指定实际观察范围内的调用行。符号没有出现在已返回源码的完整行中时，不据此推断目标。

## 支持范围

- 常见 `from module import function as alias`、`import module as alias`、点分模块引用。
- 项目根目录下的模块、普通包、相对导入、常见 `__init__.py` 重新导出及子模块导入。
- 本地函数定义、类构造引用，以及类中直接定义的方法。
- 同一作用域的多个可能绑定、条件导入、模块与包同名、循环导入等情况显式记录。

`resolved` 只表示本次静态查找得到单一候选且没有已记录的不确定性，不证明运行时已经调用它。`ambiguous` 也可能表示条件绑定尚未证明执行，即使只返回一个定义。`unresolved` 表示在本次支持范围与预算内无法确认，不能据此断言整个项目没有该函数。

动态对象分派、函数参数传入的可调用对象、赋值别名、通配符导入、推导式作用域、继承方法、导入钩子及修改后的 `sys.path` 不自动推断。函数/方法的参数会遮蔽同名全局导入，不会把这类动态对象误报成全局函数。工具不自动发现 `src` 布局或第三方安装目录；调用者可以把正确的源码根目录作为绑定项目。

## 证据与版本

绑定和定义均作为实际读取的 `file_excerpt` 记录，携带路径、SHA-256、实际行范围和截断标记。定义片段可用于报告引用和修复交接；源码较长时继续分页读取。

`symbol_resolution` 记录源观察 ID、候选定义 ID、链路 ID 和依赖观察 ID。随后读到调用者、导入文件或定义文件的新版本时，旧关联会从当前观察中失效，完整历史保留。修复交接仍重新检查已观察文件的哈希，旧报告不能覆盖新代码。

工具选择策略在提取证据并获得 Python 源码观察后才开放该工具。对无堆栈数值异常，完成清单可从已读片段中的导入与调用提出一个查找建议，再由 AST 解析验证；文字匹配本身不是绑定事实。无法静态确认时记录局限，不反复重试相同目标。

## 有界读取

每次请求最多读取八个模块、单文件 200 KB、总读取 1 MB、关联深度六层、AST 节点 40,000 个。最多返回八个候选（默认六个），文件片段观察最多 32 个，单片段内容最多 4,000 字符。超限、语法错误、范围外及符号链接均显式记录；不递归扫描无关目录。

## 验收

```bash
python -m pytest tests/test_symbol_resolution.py -q
python -m corecoder.symbol_demo --output-dir .tmp/symbol-demo-new
```

离线演示实际生成无堆栈的 `loss=nan`，经过搜索、读取调用处、静态导入关联定位实现，再修改文件并执行原有限性及正常输入断言。模型决策由脚本驱动，不调用付费 API，不能用它证明通用诊断准确率。

真实项目统一验收使用新目录，保留旧记录：

```bash
python examples/m2d_fault_acceptance.py \
  --source /path/to/M2D-LIF --experiment-python /path/to/M2D/bin/python \
  --output-dir .tmp/m2d-six-case-new --live --direct \
  --env-file .env --max-requests 72 --max-case-requests 12
```

这会向已配置接口发送必要源码与日志，产生 API 用量。六例各预留 12 次，实际完成后停止，不为用满额度追加请求。受控 CPU 检查不等于完整训练恢复，也不等于公开基准成绩。

拼接校验同时覆盖默认通道拼接、同形状输入、显式维度 0/2，以及显式维度不兼容时应报错的行为。只对某个样例输入回退拼接轴的实现不算合格修复。真实 Torch 校验器回归可设置 `RESEARCHCODER_EXPERIMENT_PYTHON` 为已有 Torch 环境的 Python，再运行 `tests/test_concat_contract.py`；未设置时这三项集成测试会明确跳过。
