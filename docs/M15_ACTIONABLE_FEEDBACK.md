# Actionable feedback v3

`followup-v3` keeps v2 reference compaction and strict citation validation. A
rejected batch returns a stable failure code and at most eight canonical current
local source documents. Invalid references are classified by position; arbitrary
model strings and upstream content are not echoed. Rich hints are bounded to two
rejections. All corrections consume existing model/tool/Job allowances. No ID is
silently imported, normalized or registered, and no rejected batch is committed.

`oracle_receipt.adapt_original_result` retains the original Oracle's failure type
as bounded metadata while preserving its original score and exit code. Exception
bodies, seeds and private expected values are not forwarded. The original Oracle
is unchanged. A versioned public execution-policy text makes the already-enforced
restriction on reflection/dynamic execution explicit; it contains no fault answer.

M14 remains frozen. Any real retest uses a new protocol and records changes to the
feedback, receipt version and public policy. It is not a strict one-variable
experiment or a retroactive correction of historical results.
